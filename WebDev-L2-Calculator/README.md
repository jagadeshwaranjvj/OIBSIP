## 📖 Project Overview

JagCalci is a responsive web-based calculator designed to perform common arithmetic operations through a clean and simple interface.

The calculator supports basic mathematical operations, decimal calculations, operator chaining, deletion, clearing, percentage calculations, and keyboard input.

The project was developed using only HTML, CSS, and Vanilla JavaScript without using external frameworks or libraries.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage / Modulo operation
- Decimal number support
- Operator chaining
- Division-by-zero error handling
- Clear (`C`) function
- All Clear (`AC`) function
- Delete (`DEL`) function
- Equals (`=`) calculation
- Keyboard support
- Responsive design for smaller screens
- Live expression display
- Clean and modern calculator interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
