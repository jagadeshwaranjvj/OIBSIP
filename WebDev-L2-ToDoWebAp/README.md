# To-Do Web App

A responsive and interactive To-Do Web App developed as part of the Oasis Infobyte Web Development and Designing Internship.

## Project Objective

The objective of this project is to develop an interactive task management application that allows users to create, complete, edit, and delete daily tasks while keeping pending and completed tasks organised separately.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Features

- Add new tasks
- View pending tasks
- Mark tasks as completed
- Move completed tasks to the Completed Tasks section
- Edit tasks inline
- Delete tasks
- Pending task counter
- Completed task counter
- Task timestamps
- LocalStorage persistence
- Empty-state messages
- Responsive design
